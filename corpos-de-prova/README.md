# Corpos de prova
Antes das peças grandes, preparar famílias de furos/eixos, alojamentos de rolamento, rasgos/pinos, articulações, fixações e roscas. Valores da matriz são definidos conforme peças reais, resolução da máquina e ajuste desejado; não há série dimensional aprovada.

Para cada amostra: ID, revisão, dimensão nominal, dimensão medida, orientação, material/lote, perfil, instrumento, repetição, esforço de inserção e ajuste escolhido. Registrar em testes/registro.csv e devolver compensações aos parâmetros. Corpos de prova ainda não modelados.
